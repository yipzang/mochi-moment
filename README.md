# 糯糯 — 沉浸式搗麻糬

使用 Next.js、React 和 Three.js 製作的 3D 搗麻糬小玩具。

- 單人模式：點按或空白鍵敲擊，長按連續敲擊，自動模式
- 雙人同屏：A / L 鍵分工敲擊與翻面，可交換左右手
- 原味、抹茶、草莓配色，局部拉扯與回彈動畫
- 可旋轉、縮放的 3D 視角及重設功能
- 繁體中文、日本語、한국어
- 響應式介面與可關閉的合成音效

## 本機執行

```sh
npm ci
npm run dev
```

開啟 http://localhost:3000 。

## 正式部署

```sh
npm ci
npm run build
npm start
```

在 Vercel 匯入此倉庫，框架選 Next.js，根目錄使用倉庫根目錄，其他建置設定使用預設即可。目前不需要環境變數或資料庫。

## 模型

public/models 包含三份壓縮後的 GLB，合計約 16 MB。貼圖採用 WebP，最高 1024px；木臼與木槌經減面，麻糬保留頂點以支援程式變形。需支援 WebGL 的現代瀏覽器。

雙人模式為同屏操作，並非遠端連線。計數在重新載入後重設；語言偏好保存在本機瀏覽器。
