# 糯糯 — 沉浸式搗麻糬

繁體中文 · [日本語](#日本語) · [한국어](#한국어)

使用 Next.js、React 和 Three.js 製作的響應式 3D 搗麻糬小玩具。

**線上體驗：[糯糯 Mochi Moment](https://mochi-moment.hitmochi.workers.dev/)**

- 單人模式：點按或空白鍵敲擊，長按連續敲擊，自動模式
- 雙人同屏：A / L 鍵分工敲擊與翻面，可交換左右手
- 原味、抹茶、草莓配色，局部拉扯與回彈動畫
- 可旋轉、縮放的 3D 視角及重設功能
- 繁體中文、日本語、한국어
- 響應式介面與可關閉的合成音效

## 本機執行

```sh
npm ci
npm run dev
```

開啟 http://localhost:3000 。

## 正式部署

目前部署於 Cloudflare Workers，以 Next.js 靜態匯出方式提供網站，不需要資料庫或應用程式環境變數。

- `next.config.mjs` 設定 `output: 'export'`，建置產物在 `out/`。
- `wrangler.jsonc` 設定建置命令 `npm run build` 與靜態資源目錄 `./out`。
- Cloudflare 已連接本倉庫；推送至 `main` 後自動建置部署。
- Cloudflare 建置設定：根目錄 `/`，獨立 Build command 留空，Deploy command 為 `npx wrangler deploy`（由 Wrangler 執行建置）。

手動部署時，先完成 Cloudflare CLI 登入，再執行：

```sh
npm ci
npx wrangler deploy
```

只檢查正式建置可執行 `npm run build`。靜態匯出不使用 `npm start` 啟動正式服務。

## 模型

public/models 包含三份壓縮後的 GLB，合計約 16 MB。貼圖採用 WebP，最高 1024px；木臼與木槌經減面，麻糬保留頂點以支援程式變形。需支援 WebGL 的現代瀏覽器。

雙人模式為同屏操作，並非遠端連線。計數在重新載入後重設；語言偏好保存在本機瀏覽器。

## 後續計畫

- 優化模型載入速度：木槌與木臼進一步減面、幾何壓縮及載入體驗改善。目前三份模型合計約 16 MB，首次載入較依賴網路速度。
- 增加木槌樣式及更多麻糬配色。
- 購買自訂網域後綁定現有 Cloudflare Worker。

**糯糯 Mochi Moment — 3D 餅つきミニゲーム**

[ブラウザーで遊ぶ](https://mochi-moment.hitmochi.workers.dev/)

Next.js・React・Three.js で制作した、スマートフォンにも対応する餅つきゲームです。

- **ひとりで遊ぶ：** タップまたはスペースキーで餅をつきます。長押しで連続操作、自動モードにも対応しています。

- **見た目と操作：** プレーン・抹茶・いちごの色を選べます。ドラッグで視点を回転し、ホイールまたはピンチで拡大・縮小できます。

### 起動とデプロイ

ローカルでは `npm ci` → `npm run dev` を実行し、`http://localhost:3000` を開きます。

本番サイトは Next.js の静的エクスポートを Cloudflare Workers で配信しています。`main` へのプッシュで自動デプロイされます。手動デプロイは Cloudflare CLI へのログイン後、`npm ci` → `npx wrangler deploy` を実行します。Wrangler が `npm run build` を実行し、`out/` を配信します。データベースやアプリ用環境変数は不要です。静的エクスポートの本番配信に `npm start` は使用しません。

### 現在の制限と今後の予定

WebGL 対応ブラウザーが必要です。3 個のモデルは合計約 16 MB あるため、初回の読み込み時間は通信速度によって変わります。回数はページを再読み込みするとリセットされ、言語設定はブラウザーに保存されます。

今後はモデルの軽量化と読み込み体験の改善、杵のデザインや餅の色の追加、独自ドメインの設定を予定しています。

### 실행 및 배포

로컬에서는 `npm ci` → `npm run dev`를 실행한 뒤 `http://localhost:3000`을 엽니다.

현재 서비스는 Next.js 정적 내보내기를 사용하며 Cloudflare Workers에서 호스팅합니다. `main`에 푸시하면 자동으로 배포됩니다. 수동 배포는 Cloudflare CLI에 로그인한 뒤 `npm ci` → `npx wrangler deploy`를 실행합니다. Wrangler가 `npm run build`를 실행하고 `out/` 폴더를 배포합니다. 데이터베이스나 앱 환경 변수는 필요하지 않습니다. 정적 내보내기의 운영 서비스에는 `npm start`를 사용하지 않습니다.

### 현재 제한 및 향후 계획

WebGL을 지원하는 브라우저가 필요합니다. 모델 3개의 총용량은 약 16 MB이므로 첫 로딩 시간은 네트워크 속도에 따라 달라집니다. 횟수는 페이지를 새로고침하면 초기화되고, 언어 설정은 브라우저에 저장됩니다.

모델 용량과 로딩 경험 개선, 떡메 디자인 및 떡 색상 추가, 사용자 지정 도메인 연결을 향후 진행할 예정입니다.
